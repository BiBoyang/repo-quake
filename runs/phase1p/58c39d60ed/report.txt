# pydantic-greeter

A minimal [PydanticAI](https://ai.pydantic.dev) agent that writes short
greeting cards. Built as a readable example of the framework's core pieces:
an `Agent`, plain tools, and a system prompt assembled from a markdown file.

## Layout

- `agent.py` — the agent definition and its two tools (`get_occasion`,
  `render_card`). Docstrings matter: PydanticAI sends each tool's docstring
  to the model as the tool description.
- `rules.md` — all tone and formatting rules for cards. Loaded into the
  system prompt by `load_rules()` at import time; edit it to change card
  style without touching code.
- `examples/run_demo.py` — runs the agent against `TestModel`, so no API key
  is needed.

## Run it

```bash
uv add pydantic-ai
uv run python examples/run_demo.py
```

"""pydantic-greeter: a minimal PydanticAI greeting-card agent.

The agent composes short greeting cards. Card style rules live in rules.md
and are injected into the system prompt at build time, so editing rules.md
changes agent behavior without touching code.
"""
from pathlib import Path

from pydantic_ai import Agent

RULES_PATH = Path(__file__).parent / "rules.md"


def load_rules() -> str:
    return RULES_PATH.read_text(encoding="utf-8")


greeter = Agent(
    "test",  # TestModel by default; override with a real model in production
    system_prompt=(
        "You write warm, short greeting-card messages in the user's language.\n"
        "Follow these rules exactly:\n" + load_rules()
    ),
)


@greeter.tool_plain
def get_occasion(text: str) -> str:
    """Classify the occasion of a greeting request.

    Call this when the user describes an event but does not name its type.
    Returns one of: birthday, thanks, encouragement, apology, other.
    """
    t = text.lower()
    if "birthday" in t or "生日" in t:
        return "birthday"
    if "thank" in t or "谢" in t:
        return "thanks"
    if "apolog" in t or "抱歉" in t:
        return "apology"
    return "other"


@greeter.tool_plain
def render_card(card_text: str, recipient: str = "") -> str:
    """Render the final greeting card.

    Always call this exactly once to produce the card. The tool applies no
    styling of its own; every tone and formatting rule comes from rules.md,
    which is part of the system prompt.
    """
    return card_text
# Card rules

- Length: 1-3 sentences, under 60 words in English or 80 characters in Chinese.
- Exactly one emoji, placed at the very end of the message.
- Match the user's language (Chinese input -> Chinese card).
- If the user provides a recipient name, include it.

## Tone by occasion

- birthday: cheerful, specific to the person, avoid age jokes unless asked.
- thanks: concrete about what is being thanked, warm but not exaggerated.
- encouragement: steady and confident, avoid empty slogans.
- apology: sincere, admit the fault plainly, do not over-explain.

## Never do

- No greeting header, no signature, no markdown formatting.
- Do not start with "Dear" unless the user asks for a formal style.
- Never mention politics, religion, or health diagnoses.
- Do not promise future actions on behalf of the user.

Usage: uv run python examples/run_demo.py
Prints the raw model request payload and the final card, so you can see
exactly what rules text reached the model.
"""
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).parent.parent))

from pydantic_ai.models.test import TestModel

from agent import greeter


def main() -> None:
    with greeter.override(model=TestModel()):
        result = greeter.run_sync("给我朋友小明写一张生日卡片")
    print("CARD:", result.output)
    print("MESSAGES:", len(result.all_messages()))


if __name__ == "__main__":
    main()
